# Duo Fold 折机游戏 · 玩法设计 v0.1

> 核心定位：**赌博式折机模拟器**
> 一句话：你每折一下，它可能升阶、可能白折、可能当场碎成渣。越往后越危险，而你可以随时收手把成绩做成卡片。

---

## 一、核心循环

```
新机入手 → [折] → 判定 → 升阶 / 不变 / 碎裂
                      ↓
              本体特效变化（裂纹、绿线、闪屏、折痕加深）
                      ↓
          继续折（更危险、更高阶） 或 收手出卡（落袋为安）
```

**博弈结构**：经典的「贪心还是落袋」。碎裂 = 一切归零；主动收手 = 成绩定格。
完美复刻锻造类游戏的心跳感，但赌注是一台 15999 的手机。

---

## 二、品阶标签体系（10 阶）

从「一尘不染」滑向「玄学传家宝」。名字本身就是笑点：折得越烂，称号越离谱。

| 阶 | 标签 | 视觉表现 | 备注 |
|----|------|---------|------|
| 1 | 全新未拆封 | 干净亮面，无痕 | 起点 |
| 2 | 初见折痕 | 中线泛起一道浅痕 | |
| 3 | 折痕明显 | 折线变深，侧光可见 | |
| 4 | 偶发闪屏 | 屏幕随机闪烁 | 解锁"闪屏"粒子 |
| 5 | 一缕绿线 | 折线处一条荧光绿竖线 | 绿色开始入侵 |
| 6 | 触控时灵 | 触点漂移抖动 | 交互开始"不听话" |
| 7 | **久经沙场** | 裂纹网状蔓延 + 边缘掉漆 | 用户指定必留 |
| 8 | 战损成色 | 半屏坏点 + 铰链异响 | |
| 9 | 厂商拒保 | 整屏裂纹 + 边框变形 | 讽刺顶点 |
| 10 | 传奇·一掰就碎 | 荧光绿图腾 + 金色描边 | 稀有度天花板 |

> 命名原则：越往后越荒诞。**「久经沙场」是全游戏的情绪锚点**，多数玩家会死在第 6-8 阶。

## 三、判定与数值（第一版，待实测调参）

### 每次「折」的三分支

```
P_break = 0.04 + 0.011 × folds + 0.020 × (stage - 1) + item_break_bonus
P_up    = 0.55 × 0.82^(stage - 1)
P_same  = 1 - P_break - P_up
```

| 折叠次数 | 碎裂率（1 阶） | 碎裂率（5 阶） | 碎裂率（8 阶） |
|---------|---------------|---------------|---------------|
| 1 | 4% | 12% | 18% |
| 10 | 15% | 23% | 29% |
| 20 | 26% | 34% | 40% |
| 30 | 37% | 45% | 51% |

- 期望寿命约 **18-25 次折叠**（不道具备份）
- 「不变」是最磨人的区间：白折一次，风险却涨了
- 每阶升阶率：55% → 45% → 37% → 30% → 25% → 20% → 17% → 14% → 11%
  → 无道具平均能摸到 **4-5 阶**，摸到 8 阶以上约 **1-2%**

### 暗改空间（后续）
- 前 3 折加"新手保护"，碎裂率减半 → 避免开局暴死
- 连续 3 次"不变"后给一次"手感补偿" → 减少挫败感

## 四、道具系统

| 道具 | 来源梗 | 效果 | 代价 |
|------|--------|------|------|
| **吹风机** | 网友用吹风机撕下纳米纹理磨砂层，屏幕秒变亮面 | 本次折叠**升阶率 ×2.2**；视觉变成亮面（折痕全暴露） | 永久 **+6% 碎裂率**；保修标记变灰 |
| **沙子** | JerryRig 测试：一把沙卡进铰链，手机合不上 | 本次折叠**必定不碎**（硬扛一次） | 永久 **+4% 碎裂率**，且铰链异响（每次折额外 +1%） |
| **延保**（可选） | 7998 元 vs 628 元 | 碎裂时**免死一次**，手机回血到当前阶 | 最终卡片标签**降一阶** + 标注"靠保险活下来的" |

**道具经济学**：吹风机是"加速器"，沙子是"护身符"，AC+ 是"赎罪券"。
三者都是"用未来的安全换现在的进度"——和现实中折叠屏用户的处境完全同构。

## 五、成就卡片（传播核心）

### 规格
- 竖版 **1080 × 1440**，适配朋友圈 / 小红书 / X
- 配色：黑灰白 + 荧光绿（#00FF88）点缀，日系极简
- 导出：PNG 下载 + Web Share API（移动端直接分享）

### 版式

```
┌────────────────────────────┐
│  DUO FOLD 折叠耐力测试    │  ← 小字编号 + 日期
│                            │
│        [手机裂纹图案]       │  ← 按折叠次数程序化生成
│                            │
│      久经沙场              │  ← 品阶大字
│      STAGE 07 / 10         │
│                            │
│   折叠 34 次               │  ← 核心数字，最大号
│   ────────────────         │
│   吹风机 ×2   沙子 ×1      │  ← 道具记录
│   存活 4 分 12 秒          │
│                            │
│  "客服：属人为损坏。"       │  ← 随机评语
└────────────────────────────┘
```

### 随机评语库（举例）
- 「客服：属人为损坏。」
- 「你确实没用力，它确实碎了。」
- 「延保 已于上月到期。」
- 「第 35 次，你听见了咔嚓。」
- 「已为您更换新机（新机同样易碎）。」
- 「不买 延保，就不 care 你。」

### 碎裂结局的卡片
碎裂也给卡，但做成"死亡证明"：黑底、红字、品阶灰掉，标题「报废通知」。败者也有传播点。

## 六、视觉与手感

- 风格：黑白灰极简 + 荧光绿点缀（明日方舟式高对比），反 Q 版
- 手机本体：正面视角，中线纵向折痕
- 关键手感：
  - 折叠动画有"阻尼"，不是匀速
  - 碎裂瞬间：屏幕白闪 → 绿线窜出 → 触控图标乱跳 → 黑屏
  - 音效：铰链咔哒、玻璃细裂、电流滋啦
- 屏幕抖动/残影：每次折后轻微不稳，暗示"它快不行了"

## 七、技术架构

### 引擎与导出
- **Godot 4.6.3**（本机 `D:\godot\godot.exe`）
- Web 导出：**单线程模式**（`thread_support = false`）
  - 好处：不需要 COOP/COEP 响应头，GitHub Pages / Vercel / 任意静态托管直接跑
  - 代价：无多线程，对本游戏无影响
- 包体预估：wasm 约 30-40MB，gzip 后 **10-13MB**（首屏 3-8 秒，可加加载动画掩盖）

### 场景结构（首版）
```
Main (Control)
├── PhoneView        手机本体绘制 + 形变
├── EffectLayer      裂纹/绿线/闪屏粒子
├── HUD              折叠次数、品阶、风险条
├── ItemBar          吹风机 / 沙子 / AC+
└── CardExporter     成就卡片渲染（SubViewport → Image → PNG）
```

### 卡片导出路径
`SubViewport` 渲染 → `get_texture().get_image()` → `save_png()` → JavaScriptBridge 触发浏览器下载
（Web 端需要走 `JavaScriptBridge.eval` 调 `a.download`）

### 发布
- 静态托管：GitHub Pages（silent-reader-cn 账号）
- 分享短链带参数：`?f=34&s=7&i=fan2,sand1` → 打开直接展示成就卡片（病毒式传播）
