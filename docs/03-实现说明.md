# 03 · 实现说明

面向维护者。玩家向的说明在 [README](../README.md)，玩法设计在 [02-玩法设计-v0.1.md](02-玩法设计-v0.1.md)。

## 一、技术栈

纯静态 Web：Three.js r186 + 原生 ES module，无构建步骤，`http://` 直开；gzip 后约 420KB。
数值系统与词条池在 `web/src/logic.js`，文案在 `web/src/i18n.js`，成绩卡用 canvas 现画。

## 三、本地运行

```bash
cd web
python serve.py --port 21000 --bind 0.0.0.0   # 带 Cache-Control: no-store 的预览服务
# 打开 http://localhost:21000
```

**别用 `python -m http.server`**：它只发 `Last-Modified`，手机浏览器会按启发式缓存 ES module，部署后容易出现「新 `main.js` 配旧 `logic.js`」，整条模块图挂掉、只剩静态外壳（模型空白）。`serve.py` 强制 `no-store`，并给 `.mjs` 发正确的 `text/javascript`。

无需构建：`index.html` 通过 importmap 直接加载 `vendor/` 里的 three。

## 四、启动守卫

`index.html` 里有一段内联脚本（不经过模块缓存，模块全挂它也能跑）：

- 捕获 `error` / `unhandledrejection`，把原文写进页面底部的红色诊断条
- 3.5 秒内 `window.__duo` 仍未就绪，就逐个 `fetch` 模块文件，明确说出**是哪个文件没取到**（`./src/i18n.js` 也在探测清单里）
- 附「重试」按钮：带时间戳重新请求文档，配合 `no-store` 甩掉旧缓存

排查线上白屏先看这条。它自带一份中英小词典——报错信息也要用玩家能读的语言。

## 五、双语实现

### 结构

`src/i18n.js` 是唯一文案来源，一条 key 对一份 `[中文, 英文]`：

```js
DICT['hud.book'] = ['成就', 'Awards'];
t('log.acLeft', { n: 2 })   // → '这台机器还能再保 2 次。…'
```

导出：`t(key, params)`、`pick(keys)`（随机台词）、`applyStatic(root)`（刷 DOM）、`getLang()`、`setLang(l)`、`onLangChange(fn)`。

### 判定顺序

1. URL `?lang=xx`（会写进 localStorage，之后直接进站也生效）
2. localStorage `duofold.lang`
3. `navigator.languages` 里第一个支持的语言（`zh*` → zh，`en*` → en）
4. 兜底英文——非中文环境一律英文，不猜

### 静态文案约定

`index.html` 上三种标记，由 `applyStatic()` 统一刷：

- `data-i18n="key"` → `textContent`
- `data-i18n-html="key"` → `innerHTML`（模板里带 `<b>` 的，比如「折叠 N 次」）
- `data-i18n-attr="aria-label:key,title:key"` → 指定属性

### 防闪屏

文案刷完之前界面不该露字，否则英文用户会看到一帧中文：`<head>` 里给 `<html>` 挂 `.i18n-wait`，CSS 把 HUD 与底部面板 `visibility: hidden`，`applyStatic()` 结束时摘掉；同时有 3 秒兜底，脚本挂了也不会永久隐藏。

### 踩过的坑（改这块前先看）

- **`t` 这个名字在本项目里到处都是**：`main.js` / `card.js` 的遍历回调曾用 `t` 代表 trait，`phone.js` 里 `t` 是动画时间（`const { stage, broken, t = 0 } = st`）。`phone.js` 因此以 `import { t as tr }` 导入，`showRarityBanner(trait, rarity)` 的参数也改过名。新增取词调用前，先确认作用域里没有同名变量。
- **成绩卡是 canvas 重绘的**，不是 DOM：字体栈要按语言换（英文不再套中文字体栈），英文印章字更长，字号单独收一档（19 / 17px）否则顶出圆环。
- **表格判定列以前靠比较中文字面量**（`row[2] === '异常'`）上色，双语后改成布尔标记 `bad`，别再退回字面量比较。
- **启动守卫的词典是故意重复的**：i18n 模块自己 404 时它还得能说话，所以它只做「读 `<html data-lang>`，读不到再自己判一次」。

### 加一门语言要改哪几处

`LANGS` + `normalize()` 各加一档 → `DICT` 每条补一列（没有的走中文兜底，不会崩）→ `applyStatic()` 里的 `<html lang>` 映射 → `card.js` 的字体栈与印章字号 → 启动守卫小词典。

## 七、关键技术点

- **折叠屏幕是一整块细分网格**，按弧长实时重算顶点；弯曲半径由机身厚度决定（`R = THICK/2`），不是自由参数
- **屏幕不参与深度测试**（`depthTest: false` + `renderOrder: 10`）：它与机身表面只差几毫米，深度精度不足以区分
- **折叠透视模糊**用自定义 shader：折线附近做 5×5 采样模糊 + 暗化 + 冷色偏移
- 屏幕圆角靠着色器 `discard` 实现，canvas 圆角外必须 `clearRect` 而不是填充

### 成就页词条卡：四档稀有度各自一套配色

- 卡片是「透明 border + 双层 background」：第一层 `padding-box` 是卡面，第二层 `border-box` 是渐变描边；四个变量 `--rc`（文字主色）/ `--rl1..3`（描边渐变）/ `--rtint`（左上角底光）按 `.r-common` `.r-rare` `.r-epic` `.r-legendary` 覆盖。
- 层级差别落在**边框粗细 + 光**上：普通 1px 冷银不发光 → 稀有 1px 亮蓝 + 淡蓝外环 → 史诗 2px 紫洋红 + 重辉光 → 传说 2px 金 + 呼吸辉光 + 旋转扫光（`::after` 的 `conic-gradient`，`prefers-reduced-motion` 下停转、留一块静态柔光）。
- 文字色用**提亮版**，不要直接拿 `RARITY[].color` 写字：标题 13.5px/700（宽屏 14.5px）、描述 `#b4bbc6`、次数 `#9aa2ae`，与卡面底色对比度 6.9~12:1，全部过 WCAG AA。
- 稀有度标签独占一行贴右、标题整行铺开（`order` + `flex: 1 0 100%`）：否则英文长名（A Thread of Green）会被标签挤成三行。
- 宽屏（`min-width: 820px`）面板放宽到 700px 并改三列 + 字号提一档；手机维持两列。
- `fresh`（本次新解锁）用绿环压过稀有度辉光，并给 `.fresh.r-legendary` 关掉呼吸动画，避免两套动画抢同一个 `box-shadow`。
- 命名坑：场上词条胶囊是 `.trait.r-xxx`（`currentColor` 上色），成就卡是 `.book-trait.r-xxx`，两者选择器不重叠，改一边不会串色。
- **卡面也按档染色**：卡面底色是 `color-mix(in srgb, var(--rc) 11%, #1c2028)` → `5% + #0b0d12`，四档不再是同一块深灰；染色后实测对比度 标题 7.4–10.6、描述 7.9–8.2、次要 5.9–6.2，仍过 AA。
- 传说/史诗的词条卡右下角还有一个角落花纹（`.bt-orn`，SVG 当 `mask` 上色，颜色跟 `--rc` 走）：传说是双线 L 角 + 菱形钉（24px 下双弧会糊成一道乱弯的弧，别再用），史诗是叠套菱形。
- 未解锁卡不参与演出：`.locked.r-legendary` 关掉呼吸与扫光（`::after { content: none }`），只留一缕边色。

### 结算卡（导出 PNG）：稀有度皮肤 + 花纹分级

- 结算卡是 canvas 手绘（`web/src/card.js`，1080×2020 逻辑尺寸、@2x 输出 2160×4040）。canvas 读不到 CSS 变量，稀有度色定义在 `RSKIN` 表里，**与 `style.css` 的 `.book-trait.r-*` 一一对应，改色要两边一起改**。
- **卡面主题色 = 评级色**（`skinMain = GRADE_SKIN[gr.g]`：S 金 / A 紫 / B 蓝 / C 绿 / D 灰）。卡面上最醒目的是那个评级字母，主题色必须跟它一致；底纹、外框、页眉、品阶名、刻度、光晕、徽章全用同一支色。
- **碎裂不改主题色**：碎裂卡照样用评级色，靠红印章 / 判定列 / 结论红字表达「人为损坏」。否则又会出现「紫 A 配红卡面」。
- **卡高按内容算**：`H = max(2020, quoteBottom + 340)`，其中 `quoteBottom` 由词条实际行数（12 条会排成 3 行）与结论折行数推出。写死 2020 时，「结论」会被钳到固定位置，直接压在第三行胶囊上。
- 每套色带 `bg1/mid/bg2` 三级底色（把代表色混进深底），所以 S/A/B/C/D 五档的整卡底色各不相同，不是同一块蓝黑。
- 整卡只有一个主题色轴。**稀有度只体现在词条胶囊与右上统计行**（金=传说、紫=史诗、蓝=稀有、灰=普通）；花纹的**密度**仍按最高稀有度（传说→古典、史诗→几何），但**用评级色画**，所以不会出现「紫 A 配金卡面」这种撞色。
- 渐变端点一律收在同一色相里（蓝不跑青、紫不跑洋红）；页眉与品阶名用同色相提亮版 `ink`，饱和原色只用于描边、刻度、发光。
- 花纹按档分级，越稀有越繁复：
  - 传说：八芒星满版底纹 + 带端徽的横花带 + 纵向连珠边带 + 底部八角徽记（古典）
  - 史诗：菱形斜格满版底纹 + 素花带 + 菱形边带（几何）
  - 稀有：双线分隔，无花纹；普通：素面单线
- 词条胶囊按稀有度倒序排列；描边是渐变且高稀有度带自发光；形状也分档（普通圆点 / 稀有带环圆点 / 史诗菱形 / 传说八角星），右上角再给一行按稀有度的统计。原来的胶囊一律同色描边，缩到手机上几乎分不出轻重。
- 字与版：表格行高 46→52、正文字号 20→22；胶囊 38→46、字号 21→23；结论行改成左对齐，右边整段留给印章（原来居中会被章压掉尾巴）；`fitBlock()` 负责超宽时先缩字号、再按词/字折行（英文长句原本会直接溢出画布）。
- 弹窗里那张图的外发光跟 `#cardImg[data-grade]` 走（`--card-glow`，由 `gradeOf()` 写），与卡面主题色一致——别退回按稀有度取色。
- **左下角二维码**指向应用 Page：矩阵是离线一次性生成的静态数据（`web/src/qr-app.js`，URL 49 字符 / ECC=Q / v5 / 37×37，用 python `qrcode` 生成），运行时零依赖、零网络；`card.js` 的 `drawQR()` 负责画，自带 4 模块静区与纸白底板。换链接要重新生成整个矩阵。实测 2160 / 1080 / 720 / 540 宽都能扫出，390px 的弹窗缩略图低于分辨率下限扫不出（正常）。底部的条形码因此右移到二维码右侧，原来的八角徽记撤掉。

## 九、发布（GitHub Pages）

游戏在 `web/` 子目录，而 Pages 只能发布仓库根或 `/docs`，所以走 **GitHub Actions 把 `web/` 作为产物上传**：`.github/workflows/pages.yml`（push 到 `main` 或手动 `workflow_dispatch` 触发）。

流程：`checkout` → `configure-pages` → `upload-pages-artifact`（`path: web`）→ `deploy-pages`，上线地址固定为 `https://silent-reader-cn.github.io/duo-fold-game/`。

**Pages 站点必须先存在**：用 `GITHUB_TOKEN` 建不了 Pages（会报 `Resource not accessible by integration`），所以首次要管理员跑一次：

```bash
gh api -X POST repos/<owner>/<repo>/pages -f build_type=workflow
```

之后工作流就能正常发布；也可以在 Settings → Pages 里把 Source 选成「GitHub Actions」，效果一样。

**注意子路径**：站点挂在 `/duo-fold-game/` 下，所有资源引用必须是相对路径（现在都是 `./xxx`）。别改成 `/src/main.js` 这类根路径，否则本地能跑、线上全 404。
