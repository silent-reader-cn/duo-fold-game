# Duo Fold 折叠耐力测试

一个赌博式折机模拟器。你每折一下，这台 15999 元的折叠屏可能升阶、可能白折、可能当场碎成渣。
越往后越危险，而你可以随时收手，把成绩做成一张卡片发出去。

## 两个实现

| 版本 | 目录 | 技术 | 状态 |
|------|------|------|------|
| **Web 3D（主线）** | `web/` | Three.js r186，gzip 后约 420KB，`http://` 直开 | 开发中 |
| Godot（存档） | 根目录 | Godot 4.6.3，wasm 37MB，需 secure context | 冻结 |

> Godot 版因为包体 37MB + 必须 HTTPS（secure context）而放弃，保留作参考实现。
> 数值系统两版共用同一套参数。

## Web 版玩法

- **拖动折叠**：按住机身左右拖。向右折起（V 形悬停姿态，内屏始终可见），向左掰弯（更伤）
- **长按自动折叠**：按住机身 0.8 秒不动即启动，之后**按住不放**就自动连续折叠，松手立刻停（按住多久折多久）；充能过程有由弱到强的震动，启动后手指不再控制折叠角度，那 0.8 秒之后的按下也不再触发手动掰弯
- **10 阶品阶**：全新未拆封 → 初见折痕 → 折痕明显 → 偶发闪屏 → 一缕绿线 → 触控时灵 → **久经沙场** → 战损成色 → 厂商拒保 → 传奇·一掰就碎
- **25 条故障词条**：按普通/稀有/史诗/传说分级，越折越容易爆
- **道具是交易不是增强**：吹风机（必定爆「磨砂膜脱落」，代价 +15% 碎裂率）、沙子（必定爆「合不严实」，代价 +13%）
- **延保（CARE+）**：碎裂瞬间自动换机，**品阶不倒扣**（保持当前阶）。单局可用次数按「本机历史最高品阶」解锁：8 阶 2 次、9 阶 3 次、10 阶 4 次；折叠数为 0 时点延保按钮升级，局内按钮下方显示剩余续命次数
- **成就手册**：localStorage 持久化，未解锁显示 ???

## 实测数值（6 万局模拟）

| 玩法 | 平均寿命 | 平均阶 | 7 阶+ | 高 Stage + 双道具词条 |
|------|---------|--------|-------|----------------------|
| 不用道具 | 29.4 折 | 6.53 | 51.4% | — |
| 用道具 | 约 20 折 | 5.21 | 12.2% | **0.067%** |

「高 Stage 又集齐两个道具专属词条」约 1500 局出一次。

## 运行

```bash
cd web
python serve.py --port 21000 --bind 0.0.0.0   # 带 Cache-Control: no-store 的预览服务
# 打开 http://localhost:21000
```

别用 `python -m http.server`：它只发 Last-Modified，手机浏览器会按启发式缓存 ES module，
部署后容易出现「新 main.js 配旧 logic.js」导致整页 JS 挂掉、只剩静态外壳（模型空白）。
`serve.py` 强制 no-store，并给 `.mjs` 发正确的 `text/javascript`。

无需构建，`index.html` 用 importmap 直接加载 `vendor/` 里的 three。

### 启动失败怎么查

`index.html` 里有一段内联启动守卫：模块加载失败、WebGL2 拿不到、或 3.5s 内 `window.__duo`
仍未就绪时，页面底部会出现红色诊断条，直接写出**是哪个文件没取到 / 哪一步抛错**，并带一个
「重试」按钮（带时间戳重新请求，配合 no-store 可甩掉旧缓存）。排查线上白屏先看这条。

## 关键技术点

- **折叠屏幕是一整块细分网格**，按弧长实时重算顶点；弯曲半径由机身厚度决定（`R = THICK/2`），不是自由参数
- **屏幕不参与深度测试**（`depthTest:false` + `renderOrder:10`）：它与机身表面只差几毫米，深度精度不足以区分
- **折叠透视模糊**用自定义 shader：折线附近做 5×5 采样模糊 + 暗化 + 冷色偏移
- 屏幕圆角靠着色器 `discard` 实现，canvas 圆角外必须 `clearRect` 而不是填充
