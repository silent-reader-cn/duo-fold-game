# iPhone Duo 折叠耐力测试

一个赌博式折机模拟器。你每折一下，这台 15999 元的折叠屏可能升阶、可能白折、可能当场碎成渣。
越往后越危险，而你可以随时收手，把成绩做成一张卡片发出去。

## 玩法

- **折**：每次判定「碎裂 / 升阶 / 不变」，风险随折叠次数和品阶平方增长
- **10 阶品阶**：全新未拆封 → 初见折痕 → 折痕明显 → 偶发闪屏 → 一缕绿线 → 触控时灵 → **久经沙场** → 战损成色 → 苹果拒保 → 传奇·一掰就碎
- **道具**（各有限次）：吹风机（保一折不碎 + 升阶率翻倍）、沙子（硬扛一折）、AppleCare+（免死一次，标签降一阶）
- **成就卡片**：随时收手或碎屏时自动生成 1080x1440 PNG

## 实测数值（20000~30000 次模拟）

| 指标 | 数值 |
|------|------|
| 平均寿命 | 11.4 折（中位 11，90 分位 18） |
| 平均最终阶 | 5.54 / 10 |
| 到达 7 阶+ | 29.5%（用道具 46.6%） |
| 传奇（10 阶） | 1.0% |

调参脚本：`tools/sim.gd`、`tools/sim_params2.gd`、`tools/sim_items2.gd`

## 运行

桌面预览：
```
godot --path .
```

Web 导出：
```
godot --headless --path . --export-release "Web" build/web/index.html
python -m http.server 8123 --directory build/web
```

## 目录

```
├── main.tscn            主场景
├── project.godot        项目配置（1080x1440 竖版）
├── export_presets.cfg   Web 导出预设（单线程，静态托管可用）
├── scripts/
│   ├── main.gd          游戏逻辑 + UI
│   ├── phone_view.gd    手机本体绘制（裂纹/绿线/坏点/闪屏）
│   └── card_view.gd     成就卡片绘制
├── audio/               程序合成的音效（无外部素材）
├── fonts/game.otf       思源黑体子集（GB2312 全集，2.77MB）
├── tools/               数值模拟与截图自检脚本
└── docs/                舆论调研 + 玩法设计
```

## 已知事项

- Web 包 wasm 37.7MB（未压缩），首次加载数秒
- 卡片下载走 `JavaScriptBridge.eval`，浏览器端尚未实测
- 字体必须内嵌：`SystemFont` 在 wasm 沙箱里拿不到系统字体，会全变方块
- 项目为讽刺模拟器定位，不含 Apple 官方素材，不代表对真实产品的质量指控
